本章要讲什么

Overview

it 可以指代人或物，可以表示时间、距离、天气，可以作形式主语、形式宾语，也可用于构成强调句。高考翻译的主要考查点集中在 it 作形式主语、形式宾语以及强调句。本章分四块逐一讲解：

一

it 的指代

天气 · 时间 · 距离
二

形式主语

for / of + sb. + to do
三

形式宾语

think / make it + 宾补
四

强调结构

It is / was … that / who
🧭
一条主线：翻译时先看提示词（圈定考查的 it 用法）→ 再判断功能（指代 / 形式主语 / 形式宾语 / 强调）→ 套固定句型 → 核对 that / who / to 等不遗漏。
💡
讲解部分的案例先不显示译文，点开「点击查看」后，句中运用 it 的部分已加粗高亮；每节后附「真题自测」，先遮住答案自行翻译。
一 · it 的指代

it 的指代作用

Referential it

it 可指代天气、时间、距离等，翻译时中文往往没有对应的「它」，需按英语习惯补出 it。

案例 · 提示词 rain
天要下雨了。
▸ 点击查看译文与讲解
It is going to rain.
分析：「天气」这里译成 it，不能直译为 weather。平时要注意积累 it 的习惯用法。
天

指代天气

It is going to rain.
时

指代时间

It is five o'clock.
距

指代距离

It is 20 minutes' walk.
一 · it 的指代

与时间相关的 it 句型

Time Patterns
句型含义例
It is time for sb. to do sth.是某人做某事的时间了It is time for us to take measures.
It is + 一段时间 + since…从……起已有多久了It is over 20 years since I came here.
It was / will be + 一段时间 + before…过了多久才……It will be long before he comes back.
案例 1 · 提示词 address
是该我们采取有效措施解决全球变暖问题的时候了。
▸ 点击查看译文与讲解
It is time for us to take effective measures to address global warming.
分析：「是该……的时候了」用固定句型 It is time for sb. to do sth.
案例 2 · 提示词 It
自从我开始教英语至今已有 20 多年了。
▸ 点击查看译文与讲解
It is over 20 years since I started teaching English.
分析：「自从……已……」用 It is + 时间段 + since，since 从句用一般过去时 started。
二 · 形式主语

it 作形式主语

Formal Subject

当动词不定式（短语）或动名词作主语时，通常用 it 作形式主语，把真正的主语放在谓语之后。

案例 · 提示词 easy
由于缺乏社会经验，大学生很容易遭受诈骗。
▸ 点击查看译文与讲解
It is easy for college students to fall victim to fraud for lack of social experience.
分析：真正的主语是 to fall victim…（太长），用 it 作形式主语顶到句首，构成 It is + adj + for sb. + to do。
句式 1It is + 形容词 + for + sb. + to do sth.
句式 2It is + 形容词 + of + sb. + to do sth.
🔑
两条注意：① 这两个句型中的 it 一般不译出来；② 二者含义接近、通常用 for，但当形容词是修饰人的属性时（如 nice、kind、polite）用 of。
二 · 形式主语

for / of 的案例 · 其它句型

Formal Subject
案例 1 · 提示词 kind
你开车送我们回家，真是太客气了。
▸ 点击查看译文与讲解
It is kind of you to send us home in your car.
分析：kind 修饰「你」这个人 → 用 of。
案例 2 · 提示词 necessary
我们每个人参与志愿者工作，是很有必要的。
▸ 点击查看译文与讲解
It is necessary for every one of us to participate in volunteer work.
分析：necessary 修饰「参与志愿工作」这件事 → 用 for。
其它需记忆的 it 句型含义
It takes sb. some time to do sth.某人用了……时间做某事
It is no use / no good doing sth.做……是没有用的
It is up to you to decide…由你决定做……
💡
it 在主语从句中的使用（It is said / claimed that…）见第四章「主语从句」一节。
三 · 形式宾语

it 作形式宾语

Formal Object
基本结构主语 + believe / consider / feel / find / imagine / make / regard / suppose / think + it + 宾补（形容词/名词）+ 不定式 / 动名词 / 从句
案例 1 · 提示词 it
我发现在这么短的时间内很难完成这项艰巨的任务。
▸ 点击查看译文与讲解
I find it hard to finish this difficult task in such a short time.
分析：find 可接宾语从句，也可接复合宾语。用 it 作形式宾语时构成 find it + adj + to do；真正宾语是 to finish…。也可译成宾语从句：I find (that) it is hard to…，两种都对。
案例 2 · 提示词 it
学校定了一条规则，开始上课时学生要起立。
▸ 点击查看译文与讲解
The school made it a rule that students should stand up at the beginning of the class.
分析：make 后不可直接跟宾语从句，但可用复合宾语，所以这句只能用 it 作形式宾语：make it + 名词 + that 从句。
三 · 形式宾语

其它常见固定句式

Formal Object
句式含义
sb. will see to it that…某人将确保……
sb. would appreciate it if…如果……某人将不胜感激
take it for granted that…想当然地认为……
例 · 提示词 favour
如果你能帮我个忙，我将不胜感激。
▸ 点击查看译文与讲解
I would appreciate it if you can do me a favour.
分析：appreciate 后接名词/代词作宾语，再接 if 从句表示条件；这里的 it 不能省略。
⭐
记法：这几个固定搭配里的 it 都是形式宾语，后面紧跟 that / if 从句才是真正的内容，考试中 it 不可遗漏。
四 · 强调结构

it 用于强调结构

Emphatic it
强调句结构It + be + 被强调部分 + that / who + 剩余部分

强调句可强调主语、宾语、状语和从句。用强调句翻译要注意两点：① that / who 不能遗漏；② 强调句不影响句子成分，只是强调某一部分，要注意被强调部分的完整性。

案例 1 · 强调主语 · 提示词 It
正是他们把事故中受伤的人送进医院。
▸ 点击查看译文与讲解
It was they that / who sent the people injured in the accident to the hospital.
分析：强调的是主语，不能用宾格 them，要用主格 they；还要注意不要遗漏 that / who。
案例 2 · 强调地点状语 · 提示词 It
就在这个公园将进行唱歌比赛。
▸ 点击查看译文与讲解
It is in this park that the singing competition will be held.
分析：强调的是地点状语，被强调部分要完整，不能遗漏介词 in。
四 · 强调结构

强调原因状语 · 三点注意

Emphatic it
案例 3 · 强调原因状语 · 提示词 It
正是因为听取了专家的意见，我们才取得这么大的进步。
▸ 点击查看译文与讲解
It was because we took the advice of the specialists that we made such great progress.
分析：强调原因状语要用 because（不用 since / as），且不要漏掉后面的 that。
1

不能漏 that / who

连接词是强调句的标志，漏了就错。
2

强调主语用主格

强调人作主语用主格，不能用宾格。
3

被强调部分要完整

强调状语时介词（in / by / for）不能丢。
💡
判断方法：把 It is / was … that / who 去掉后，若句子依然完整、语序通顺，就是强调句；否则不是。

小结

本章小结 · 高频易错点

Recap

it 的指代

  • 天气 / 时间 / 距离 → it
  • It is time for sb. to do
  • It is + 时间 + since（从句用过去时）

形式主语

  • It is + adj + for / of + sb. + to do
  • 修饰人 → of（kind/nice）
  • It takes sb. time to do

形式宾语

  • think / find / make + it + 宾补
  • make it a rule that…
  • appreciate it if / see to it that

强调结构

  • It is / was … that / who
  • 强调主语用主格
  • 状语介词（in/by/for）不能丢
⚠️
最易失分的四处：① 强调句漏掉 that / who；② 强调主语误用宾格（they 写成 them）；③ 强调状语漏介词（in this park 写成 this park）；④ make it a rule that 中漏掉 it。
