本章要讲什么

Overview

这一节把两个"考得最多、错得也最多"的语法点合在一起讲：情态动词（表达推测、能力、义务）和虚拟语气（表达与事实相反的假设）。它俩经常一起考——"情态动词 + have done"就是二者的交汇点，也是高考雷打不动的重点。

🧭
一条主线：判断虚拟，就一句话——"这件事跟事实相反吗？"相反，就虚拟；不相反，就正常。虚拟的核心动作是把时态往过去退一格（现在→过去式、过去→had done），这句话贯穿全章。
一 · 情态动词

常见情态动词的用法

Modal Verbs
must

一定 / 必须

肯定推测（只用于肯定句）· 主观必须
You're Tom's friend, so you must know what he likes best.
— Must we hand in? — Yes, you must. / No, you needn't / don't have to.
can/could

可能 / 能够

否定/疑问表"不可能"；can't…too/enough
It can't be Mr. Li, for he has gone to America.
You can never be too careful.（再小心也不为过）
may/might

可能 / 也许

用于肯定句、否定句
Your mother may/might not know the truth.
should/ought to

应该

ought to 与 should 同义
Young people should/ought to show respect for the old.
have to

不得不

表客观需求（区别于 must 主观）
It is raining heavily, so we have to stay at home.
need / dare

需要 / 敢于

都有"情态动词"与"实义动词"双重身份
You needn't do it yourself.（情态，用于否定/疑问）
She dare not go out alone at night.
一 · 情态动词

三个易混点

Key Distinctions

can/could vs be able to

  • be able to 有时态变化；could 只有过去时。
  • 表"成功做成某件具体的事"用 was/were able to（= managed to），不用 could。
  • 例：He was able to go to the party yesterday despite the heavy rain.

need 双重身份

  • 情态动词：need do，只用于否定、疑问。
  • 实义动词：need to do。
  • 例：You needn't do it.（情态）

dare 双重身份

  • 情态动词：dare do，用于疑问、否定、条件。
  • 实义动词：dare to do。
  • 例：How dare you say I'm unfair?（情态）
💡
记法：need / dare 做情态动词时"不戴 to、否定疑问才现身"；做实义动词时"带 to、正常变形"。看到它们，先看有没有 to、是不是否定/疑问。
二 · 情态动词 + have done

推测类：对过去的判断

Speculation
1

must have done

"肯定做过"（只用于肯定句）
It must have rained last night, for the ground is wet.
2

can't / couldn't have done

"不可能做过"
Mr. Smith can't have gone to Beijing, for I saw him in the library just now.
3

may / might have done

"可能已经做过"
You might have read about it in the papers.
🔑
一套口诀记牢：肯定推测 must have done，否定推测 can't have done，可能推测 may/might have done。注意 must 的否定推测不能是 mustn't，而是 can't——这是一个高频陷阱。
二 · 情态动词 + have done

责备类："本应该 / 本不该"

Reproach
1

should / ought to have done

"本应该做（却没做）"，含责备
You should have finished the task yesterday.
2

shouldn't have done

"本不该做（却做了）"
I shouldn't have been so harsh on him.
3

could have done

"本来可以 / 能够（却没做）"
I could have arrived on time, but I was held up by the traffic jam.
4

needn't have done

"本没必要做（却做了）"
I needn't have bought so much wine — only five people came.
⚠️
区分两组：could have done = 本可以却未做（遗憾）；must have done = 肯定做了（推测）。一个是"没做"，一个是"做了"，别搞混。同样，needn't have done（做了但多余）≠ didn't need to do（没做也没必要）。
三 · 虚拟语气

虚拟语气总框架

Subjunctive

真实条件句

  • 条件可能实现，用陈述语气。
  • 例：If it rains tomorrow, I will stay home.（主将从现）

非真实条件句（虚拟）

  • 条件与事实相反或几乎不可能实现，用虚拟语气。
  • 例：If I were you, I would help him.（我不是你）
🧭
判断口诀：先问一句"这件事是真的吗？"——是真的，正常时态；是假的/相反/几乎不可能，虚拟。虚拟的核心就是把时态往过去退一格：现在→过去式，过去→had done，将来→过去式 / should do / were to do。
三 · 虚拟语气

if 非真实条件句（三种时间）

Unreal Conditional
时间从句谓语主句谓语
与现在相反过去式（be 用 were）should / would / could / might + do
与过去相反had + doneshould / would / could / might + have done
与将来相反过去式 / should do / were to doshould / would / could / might + do
与现在相反
If he were here, he would help us.
他（现在）不在这儿。
与过去相反
If I had been free, I would have visited you.
我（当时）没空。
与将来相反
If it should rain tomorrow, we would not go camping.
明天（几乎不会）下雨。
💡
记忆抓手：从句"过去式 / had done"，主句"would + do / have done"。主句跟着从句的时间走——从句现在，主句 would do；从句过去，主句 would have done。
三 · 虚拟语气

省略 if 的倒装

Inversion

虚拟条件句中若含 were / had / should，可省略 if，把这三个词提到句首构成倒装。多用于正式、书面语：

were（与现在相反）
Were I you, I would not do it.
= If I were you, I would not do it.
had（与过去相反）
Had I been free, I would have visited you.
= If I had been free, I would have visited you.
should（与将来相反）
Should he come, tell him to ring me up.
= If he should come, tell him to ring me up.
🔑
口诀："虚拟倒装三兄弟——were、had、should，搬到句首去，if 就退休。"看到句首是 were / had / should 却不是疑问句，第一反应就是"虚拟语气省略 if 的倒装"。
三 · 虚拟语气

错综虚拟语气

Mixed Conditional

所谓"错综"，就是条件从句和主句的时间不一致——从句说的是过去，主句说的是现在。这时各自按各自的时间来定动词形式，别套同一套。

从句过去 + 主句现在
If I had followed your advice, I would be in college now.
如果当时听了你的建议，我现在就在大学里了。
从句现在 + 主句过去
If I were you, I should not have done it like that.
如果我是你，我肯定不会那样做。
💡
判断法：把从句、主句拆开，分别问"它说的是什么时候"，再各自套那个时间的虚拟形式。别让主从句互相"传染"。
四 · 虚拟句型

命令 / 要求 / 建议从句的虚拟

Demand / Suggest

表示"命令、要求、建议"的动词，其宾语从句（以及对应名词后的表语从句、同位语从句）要用虚拟语气：(should) + 动词原形，should 可省略。

常见动词：insist（坚持）、order、command（命令）、advise、suggest、propose、recommend（建议）、desire、demand、require、request、urge（要求）
宾语从句
He suggested that we (should) not change our mind.
表语从句
My advice is that you (should) work with him.
同位语从句
I am satisfied with his order that we (should) finish the task today.
⚠️
易混：suggest 有两个意思。表"建议"才用虚拟；表"暗示、表明"时用正常陈述语气。→ Her pale face suggested that she was ill.（是"暗示生病"，不用虚拟）
四 · 虚拟句型

wish / would rather / It's time / If only

Four Patterns
① wish 从句（与现在/过去/将来相反）
I wish I were a college student.（现在）
I wish I had gone to Shanghai last month.（过去）
I wish I could speak French.（将来）
② would rather + 从句
现在/将来：I'd rather you stayed home tonight.
过去：I'd rather you had told me the truth earlier.
③ It is (high) time that + 从句
It's high time that we left / should leave.
从句用过去式或 should do。
④ If only + 从句（"要是……该多好"）
现在/将来：If only I could speak the local dialect!
过去：If only our dream had come true!
🔑
一条规律串四个：它们统统遵循"与现在/将来相反 → 过去式；与过去相反 → had done"。记住这一条，四个句型不用分别背。
四 · 虚拟句型

拓展：其他虚拟结构

More Patterns
① It is important / necessary / strange that + (should) do
It is vital that a child (should) be taught how to obey public rules.
② should 表"竟然 / 居然"（不省略）
It is amazing that the boy should have learned 500 words in one month.
③ for fear that / lest / in order that / so that（目的）
He kept silent for fear that he would disturb the teacher.
Father repeated the time lest my mother (should) forget it.
④ Be it…or… / though…be（让步）
Be it cheap or not, I will get it for my parents.（不论贵贱）
Though all the world be cold, I must be kind to all.
💡
这部分是拓展拔高，认识、能看懂即可，高考重点是前面的 if 虚拟句和四个句型（wish / would rather / It's time / If only）。
五 · 真题自测

真题自测（代表题）

Practice
1 · 错综虚拟
If I hadn't been faced with so many barriers, I ___ where I am.
▸ 点击查看答案
C. wouldn't be
考点：主句表现在，用 would do。
2 · otherwise 虚拟（过去）
The workers were not better organized, otherwise they ___ the task in half the time.
▸ 点击查看答案
D. would have accomplished
考点：对过去虚拟，用 would have done。
3 · should 表"竟然"
It's strange that he ___ have taken the books without the owner's permission.
▸ 点击查看答案
B. should
考点：It is strange that 从句用 should do（虚拟）。
4 · wish 与现在相反
There is a good social life in the village, and I wish I ___ a second chance to become more involved.
▸ 点击查看答案
A. had
考点：wish 从句与现在相反，用过去式。
5 · shouldn't have done
You ___ have scolded him for his poor performance. After all, he had done his best.
▸ 点击查看答案
D. shouldn't
考点：本不该责骂，用 shouldn't have done。
6 · can 表能力
Samuel, the tallest boy in our class, ___ easily reach the books on the top shelf.
▸ 点击查看答案
C. can
考点：表能力用 can。
7 · 语法填空：情态动词
It used to be that you ___ drive for miles here without seeing another person.
▸ 点击查看答案
could
考点：过去的能力，用 could。
8 · 语法填空：虚拟过去
If the new safety system ___ (put) to use, the accident would never have happened.
▸ 点击查看答案
had been put
考点：对过去虚拟，从句 had done（此处被动 had been put）。
收尾

本章小结

Summary

情态动词 + have done

  • 推测：must（肯定）/ can't（不可能）/ may（可能）have done。
  • 责备：should（本应）/ shouldn't（本不该）/ could（本可）/ needn't（本不必）have done。

虚拟语气

  • if 虚拟：现在→过去式，过去→had done，将来→should/were to do。
  • 省略 if：were / had / should 提前倒装。
  • 错综：主从句各按各的时间。
  • 命令建议：suggest 等 + (should) do。
⚠️
最易失分的五处：① must 的否定推测误用 mustn't（应用 can't）；② could have done（没做）与 must have done（做了）混淆；③ suggest 表"暗示"时误用虚拟；④ if 虚拟的主从句时态套错；⑤ were/had/should 倒装没认出来。
